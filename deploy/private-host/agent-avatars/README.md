# Agent avatar sources

These profile images are first-party product assets:

- `thread-mention-bot.png`: original generated artwork for Buzz's deterministic
  thread-routing bot, depicting a small robot between two linked reply arcs.
- `slopd-codex.png`: the default icon from OpenAI's official Codex VS Code
  extension, version `26.5727.40816`.
- `slopd-opencode.png`: OpenCode's production desktop icon from upstream commit
  `19231fce4b70aa5f7894a0a0eb20ff29bd417db5`.
- `slopd-claude.png`: the default icon from Anthropic's official Claude Code VS
  Code extension, version `2.1.220`.
- `slopd-grok.png`: the official black SpaceXAI symbol linked by the Grok Build
  repository at commit `9fabadea800fa6e2ed8ec91c4f45f02b7e2504f4`, from `media.x.ai`.

The source artwork is unchanged. It is only resized to a 512x512 PNG canvas for
consistent Buzz profile rendering. All names and marks remain the property of
their respective owners.
